# 歌词聚焦

为 EchoMusic 歌词页添加渐进高斯模糊与当前行放大效果。

## 效果

- 当前播放行放大展示（默认 1.3 倍），颜色使用歌曲已播色
- 非当前行逐级高斯模糊，离当前行越远模糊越重
- 用户滚轮滚动时立即移除所有模糊，恢复正常歌词显示
- 停止滚动后（宿主 5 秒自动恢复跟随）重新应用效果

## 安装

1. 将 `lyric-focus` 文件夹复制到 EchoMusic 用户数据目录下的 `plugins/` 中
2. 启动 EchoMusic，进入「设置 → 插件」
3. 找到「歌词聚焦」并启用

## 设置

在插件管理页进入「歌词聚焦设置」可调节：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 启用美化 | true | 总开关 |
| 模糊步进 | 6px | 距离每增一级增加的模糊量 |
| 最大模糊 | 24px | 最远行的模糊上限 |
| 当前行缩放 | 1.3x | 当前播放行的放大比例 |
| 非当前行缩放 | 0.85x | 非当前行的缩小比例 |
| 最低不透明度 | 30% | 最远行的不透明度下限 |

## 原理

- 通过 `ctx.css.inject` 注入过渡样式至 `.lyric-line`
- 监听 `lyricStore.$subscribe` 实时跟踪当前行变化
- 轮询 `.is-scroll-highlight` 类名检测用户滚动（与宿主 `useLyricScroll` 零冲突）
- `ctx.dom.observe('.lyric-row')` 处理虚拟滚动新增的行
- 插件禁用时自动清除所有内联样式，恢复原始显示

## 兼容性

- EchoMusic >= 2.2.6-beta.10
