# 歌词美化

为 EchoMusic 歌词页添加渐进高斯模糊、当前行放大、X 偏移与旋转弯曲效果。

## 效果

- 当前播放行放大展示（默认 1.3 倍），颜色使用歌曲已播色
- 支持歌词页歌词左对齐、居中、右对齐（默认居中）
- 非当前行逐级高斯模糊，离当前行越远模糊越重
- 用户滚轮滚动时立即移除所有模糊，恢复正常歌词显示
- 停止滚动后（宿主 5 秒自动恢复跟随）重新应用效果
- 三滑块独立控制顶部 / 当前行 / 底部歌词行的 X 起始偏移，中间行自动插值
- 旋转强度控制非当前行的倾斜角度，形成弯曲感

## 安装

1. 将 `lyric-focus` 文件夹复制到 EchoMusic 用户数据目录下的 `plugins/` 中
2. 启动 EchoMusic，进入「设置 → 插件」
3. 找到「歌词聚焦」并启用

## 设置

在插件管理页进入「歌词聚焦设置」可调节：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 模糊步进 | 6px | 距离每增一级增加的模糊量 |
| 最大模糊 | 24px | 最远行的模糊上限 |
| 当前行缩放 | 1.3x | 当前播放行的放大比例 |
| 非当前行缩放 | 0.85x | 非当前行的缩小比例 |
| 最低不透明度 | 30% | 最远行的不透明度下限 |
| 顶部偏移 | 0px | 歌词列表最顶部行的 X 偏移起点（相对最左竖线） |
| 当前行偏移 | 0px | 当前播放行的 X 偏移起点 |
| 底部偏移 | 0px | 歌词列表最底部行的 X 偏移起点 |
| 旋转强度 | 4° | 非当前行的旋转角度倍率 |
| 歌词间距 | 16px | 每行歌词上下间距 |
| 歌词对齐 | 居中 | 歌词页歌词左对齐、居中或右对齐 |

## 原理

- 通过 `ctx.css.inject` 注入过渡样式至 `.lyric-line` 和 `.lyric-row`
- 监听 `lyricStore.$subscribe` 实时跟踪当前行变化
- 轮询 `.is-scroll-highlight` 类名检测用户滚动（与宿主 `useLyricScroll` 零冲突）
- `ctx.dom.observe('.lyric-row')` 处理虚拟滚动新增的行
- X 偏移使用三锚点线性插值：顶部 / 当前行 / 底部三值，中间行自动渐变过渡
- 通过 `margin-left: -200px; padding-left: 200px` 将歌词裁切边界左移，允许偏移伸入封面区域

## 兼容性

- EchoMusic >= 2.2.6-beta.10
